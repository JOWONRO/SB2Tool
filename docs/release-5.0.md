## 1. 실사용 검증

버그 제보에 대응한 부분이라 실제로 되는지 확인하고 넘어가야 한다.
제보자 환경과 다르므로 완전한 검증은 배포 후 피드백으로 마무리된다.

- [ ] **Ctrl+V 모드** — 50줄 연속 붙여넣기, 누락·중복 개수 세기
- [ ] 오른쪽 Ctrl+V로도 인식되는지 (4.0에서는 안 됐다)
- [ ] V를 꾹 눌렀을 때 한 줄만 넘어가는지
- [ ] **대사 이동 단축키** — 다른 프로그램에 포커스가 있어도 동작하는지
- [ ] 두 키 조합(Ctrl+F1 등)이 저장되고 재실행 후에도 유지되는지
- [ ] **포토샵 모드** — 자리 표시자 옵션이 꺼져 있을 때 안내 팝업이 뜨는지
- [ ] '지금 켜기'로 옵션이 실제로 켜지는지
- [ ] 대사가 들어가고 글꼴·크기가 유지되는지
- [ ] 기존 텍스트 레이어를 클릭해 수정할 때 반응하지 않는지
- [ ] **프로그램 지정 제거** — 텍스트만 불러오면 세 모드가 켜지는지
- [ ] 자동 모드 켤 때 지정 창이 뜨고, 취소 시 토글이 꺼진 채 남는지
- [ ] **매크로 모드**를 다른 모드와 같이 켜도 간섭이 없는지
- [ ] 새 로고가 창과 작업 표시줄에 제대로 보이는지

**4.0 사용자 설정 마이그레이션 확인** (중요, 클린 환경에서는 재현 안 됨)

```cmd
python -c "from PyQt5.QtCore import QSettings; s=QSettings('RingNebula','SB2Tool'); s.setValue('AdvSettings',[1,1,0,0,0,1,1,0,0]); s.setValue('NotFirstStart',True)"
```

심어놓고 실행했을 때 고급 설정이 초기화되지 않고 그대로 나와야 한다.

## 2. `.spec` 확인 및 빌드

`.spec`은 이미 고쳐뒀다 (절대경로 → 상대경로, `datas`에 icons 추가).

```cmd
.venv\Scripts\activate
pyinstaller SB2Tool.spec
```

- [ ] 빌드가 통과하는지
- [ ] `dist\SB2Tool\icons\` 에 아이콘이 자동으로 들어갔는지 (수동 복사 불필요)
- [ ] `dist\SB2Tool\SB2Tool.exe` 아이콘이 새 로고인지
- [ ] **tcl / tk 더미 폴더** — README에 적힌 그 작업. 빼먹으면 실행 시
      `Tcl data directory not found`가 재발한다 (라임 님이 제보한 오류)

```cmd
mkdir dist\SB2Tool\tcl dist\SB2Tool\tk
type nul > dist\SB2Tool\tcl\dummy.txt
type nul > dist\SB2Tool\tk\dummy.txt
```

- [ ] **글꼴이 번들에 들어갔는지** — `dist\SB2Tool\fonts\` 에 otf 2개와
      `LICENSE.txt`가 있어야 한다. Pretendard는 SIL OFL 1.1이라 배포는
      자유롭지만 **라이선스 전문을 함께 배포해야 한다.**
- [ ] 빌드본에서 `설정 > 정보` 등 창 글꼴이 굴림이 아닌지 (번들 글꼴 인식 확인)
- [ ] `dist\SB2Tool\SB2Tool.exe` 실행 → 정상 동작 확인

> 글꼴 때문에 설치파일이 약 7MB 늘어난다. 줄이려면 Bold를 빼면 되지만
> (Qt가 가짜 굵기를 만들어 쓴다) 품질이 떨어진다.

> **선택 사항**: `.spec`의 `excludes`에 `'tkinter', '_tkinter'`를 넣으면
> 위 더미 작업 자체가 없어진다. 다만 pyautogui 의존성을 건드리는 거라
> 빌드 후 전 기능 확인이 필요하다. 이번에 할지는 판단.

## 3. `.nsi` 전면 갱신

현재 `SB2ToolBeta4.0.nsi`는 HM NIS Edit이 생성한 것이라 파일이 전부 나열돼 있다
(`File` 123줄, `Delete` 129줄). 5.0은 파일 구성이 바뀌었으므로 이대로는 못 쓴다.

`SB2Tool5.0.nsi`로 새로 만들면서 아래를 반영한다.

- [ ] `PRODUCT_VERSION`을 `5.0`으로, `OutFile`을 `식붕이툴-5.0_Setup.exe`로
- [ ] **파일 나열을 `File /r "dist\SB2Tool\*.*"` 한 줄로 교체**
      (파일이 바뀔 때마다 목록을 고치지 않아도 된다)
- [ ] **언인스톨을 `RMDir /r "$INSTDIR"`로 교체**
      4.0은 `Delete`를 나열해서 목록에 없는 파일이 남았다. ㅇㅋ 님이 제보한
      "구버전이 깔려 있으면 최신 버전이 먹통"의 원인으로 보인다.
- [ ] **`.onInit`에 기존 설치 감지 추가**
      `PRODUCT_UNINST_KEY`를 읽어 이전 버전이 있으면 안내하고 언인스톨러를
      먼저 실행한다. 덮어쓰기 설치로 인한 파일 혼재를 막는다.
- [ ] `MUI_ICON` / `MUI_UNICON`을 새 로고로 교체
      (지금은 NSIS 기본 아이콘을 쓴다)
- [ ] 인코딩 주의 — 현재 파일은 `Unicode True`인데 내용은 CP949로 보인다.
      새로 만들 때 어느 쪽으로 통일할지 정하고, 한글이 깨지지 않는지 확인.

## 6. 매뉴얼 갱신

[매뉴얼 Doc](https://docs.google.com/document/d/1Q8_eX5wpb2DEgNo7Lw9LyyRXh7I09aDeYtmQ95-eyAA/edit)

이번 변경이 커서 손댈 곳이 많다. **삭제**되는 항목이 있으니 특히 주의.

| 항목 | 처리 |
|---|---|
| `3) 프로그램 지정` | **통째로 삭제**. 메뉴가 없어졌다 |
| `4) 기본 모드`의 붙여넣기(S) 설명 | **삭제** |
| `4-2) 텍스트 라인 이동(건너뛰기)` | **삭제** (A/D/Ctrl+A/Ctrl+D) |
| 자동 모드 | 켤 때 프로그램 지정 창이 뜨는 것으로 수정 |
| 포토샵 모드 | 동작 방식 전면 수정 (아래 참고) |
| Ctrl+V 모드 | 대기시간 설정 안내 추가 |
| **대사 이동 단축키** | **신규 항목 추가** (Ctrl+K) |
| 고급 설정 | 대기시간, 포토샵 연동 사용 항목 추가 |
| 지원 포토샵 버전 | `CS6, 2017~2023cc` → **2026까지 확인됨**으로 갱신 |

포토샵 모드 설명은 이렇게 바뀐다.

- 프로그램 지정이 필요 없다. 텍스트를 불러오고 포토샵 모드를 켜면 된다.
- 포토샵이 실행 중이어야 하고, **식붕이툴과 포토샵의 권한(관리자 여부)이
  같아야 한다.** 다르면 COM으로 서로를 찾지 못한다. 이건 실측으로 확인했고,
  제보된 CC2024 멈춤도 이것일 가능성이 있다.
- 자리 표시자 텍스트 옵션이 꺼져 있으면 안내 팝업이 뜨고 바로 켤 수 있다.
- 옵션을 끈 채로 쓰려면 텍스트 박스를 **Ctrl+Enter**로 닫아야 한다.
  Esc로 닫으면 포토샵이 빈 레이어를 삭제해서 대사가 들어가지 않는다.

## 8. 시트 회신

4.0 탭의 '진척 현황' 칸을 채운다. 해결된 항목은 회색 처리.

| 제보자 | 항목 | 회신 요지 |
|---|---|---|
| 나나 | Ctrl+V 씹힘 | 원인은 Ctrl 키가 아니라 클립보드 타이밍이었음. 발사 시점을 키를 뗄 때로 옮겼고, 안 되면 고급 설정에서 대기시간을 올리면 된다 |
| ㅇㅇ | 건너뛰기·중복 | 위와 동일 원인 |
| 나나, ㅇㅇ | 단축키 변경 | 대사 이동 단축키로 추가 (Ctrl+K). 다음/이전/현재 대사를 각각 지정 가능 |
| ㅇㅇ | 이전 대사로 돌아가기 | 위에 포함 |
| ㅇㅋ | CC2024 멈춤 | 라이브러리 갱신 + 연결 방식 변경. **권한 불일치 가능성**을 함께 안내하고 재확인 요청 |
| 전가의보도 | 자리 표시자 옵션 | 감지 방식을 포토샵 알림 기반으로 교체. 옵션이 꺼져 있으면 안내하고 켜준다 |
| 라임 | 30초 멈춤 | 프로그램 지정 단계 자체가 없어졌고, COM 연결은 포토샵 모드를 켤 때만 한다 |

ㅇㅋ 님과 전가의보도 님께는 **확인 요청**을 겸하는 게 좋다. 제보 환경을
재현할 수 없어서, 실제로 해결됐는지는 그분들만 확인할 수 있다.

## 남은 판단거리

- `.spec`에서 tkinter를 제외해서 tcl/tk 더미 작업을 없앨지
- 인스톨러를 HM NIS Edit 방식에서 손으로 관리하는 방식으로 바꿀지
  (`File /r` 한 줄이면 앞으로 유지보수가 훨씬 쉬워진다)
- 버전 표기를 `5.0`으로 갈지 `Beta5.0`으로 갈지 — 현재 코드는 `5.0`
- 시트를 버전별 탭으로 계속 늘릴지
